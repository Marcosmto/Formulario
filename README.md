## 📋 Sobre o Projeto

Formulário de cadastro voltado para desenvolvedores, com os seguintes campos:

- Nome e Sobrenome
- E-mail
- Área de atuação (Front-end, Back-end ou Fullstack)
- Senioridade (Júnior, Pleno ou Sênior)
- Tecnologias utilizadas (HTML, CSS, JavaScript, PHP, C#, Python, Java)
- Campo de experiência (textarea)

Ideal para praticar estruturação de formulários, validação HTML5 e estilização com CSS.
